# Code of Conduct

## Our purpose

GeoVault exists to make research data stewardship trustworthy and humane. The
project is maintained by Syed Rafi Ahmed (RS/GIS/ML Lab) and used by a community
of data custodians, researchers and auditors. Participation is an act of
professional collaboration, and this code defines the behavior that keeps the
community safe and productive for everyone.

## Scope

This code applies to the repository, issue tracker, pull requests, code
review, project chat, and any event or channel representing the project.

## Expected behavior

- Be respectful, patient and constructive in reviews and discussions.
- Use welcoming, inclusive, jargon-aware language; explain domain terms.
- Give and accept critical feedback gracefully, focused on the work.
- Respect differing viewpoints, skill levels and institutional contexts.
- Take responsibility for mistakes and fix them promptly.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks of any kind.
- Trolling, insulting or derogatory comments, and deliberate intimidation.
- Publishing private information without consent.
- Sharing datasets, credentials or licensed material outside the terms in
  `policies/rights_catalog.yaml` and the individual `LICENSE.txt` files.
- Sustained disruption of discussions or community channels.

## Enforcement

Report violations to the maintainers (Syed Rafi Ahmed, RS/GIS/ML Lab) through a
private channel — a GitHub security advisory, direct email, or an
institutional contact. All reports are reviewed confidentially.

Consequences depend on severity and may include a private warning, a request
for a formal apology, temporary or permanent removal from project spaces, or
referral to institutional authorities. Maintainers are held to the same
standards as any community member.
